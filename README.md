# Бот «залипательные шарики»

Присылаете боту видео — он накладывает на него симуляцию с шариками (как в TikTok-роликах).
Когда одна симуляция заканчивается (шарик вылетел из колец, кто-то проиграл дуэль, шарик заполнил круг),
сразу включается следующая случайная — и так до конца ролика. Звуки ударов подмешиваются к звуку видео.

Режимы: побег из колец, спиральный лабиринт, крутящийся многоугольник, шарик растёт, битва шариков, радужный след.

## Файлы
- `bot.py` — сам Telegram-бот (aiogram 3)
- `sims.py` — симуляции и плейлист, который их переключает
- `render.py` — рендер кадров и склейка через ffmpeg
- `requirements.txt` — зависимости (ffmpeg ставится пакетом `imageio-ffmpeg`, отдельно ставить не нужно)

## Запуск на Bothost
1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. На Bothost создайте нового бота, язык **Python**.
3. Загрузите файлы `bot.py`, `sims.py`, `render.py`, `requirements.txt` (архивом или через Git-репозиторий).
4. Главный файл / точка входа: `bot.py`.
5. В переменных окружения добавьте `BOT_TOKEN` = ваш токен.
   По желанию: `MAX_SECONDS` (макс. длина видео, по умолчанию 180), `WORKERS` (сколько видео рендерить параллельно, по умолчанию 1).
6. Запустите. В логах должно появиться `bot started`.

Если на тарифе мало памяти/CPU — оставьте `WORKERS=1`, остальные видео встанут в очередь.

## Команды бота
- `/start` — помощь
- `/settings` — позиция (низ/центр/верх), размер, звук, подложка, какие режимы использовать
- `/demo` — пример на чёрном фоне (20 с)

## Ограничения Telegram
- Бот может скачать видео до **20 МБ**, отправить — до **50 МБ** (если результат больше, бот сам пережмёт в 720p).
- Обойти 20 МБ можно только своим локальным Bot API-сервером — на обычном хостинге это обычно не нужно.

## Проверка без Telegram
```bash
pip install -r requirements.txt
python render.py my_video.mp4   # → out.mp4
python render.py                # → демо 20 с на чёрном фоне
```
